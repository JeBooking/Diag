fix: 双击节点后单击不再弹出右键菜单

真正的根因（上一版修的是属性面板，不是这个问题）：

litegraph 的 processMouseDown 开头有：
  if (this.pointer_is_down && is_primary) this.pointer_is_double = true;
  else this.pointer_is_double = false;
  this.pointer_is_down = true;

而 processMouseDown 主流程里判定是否弹右键菜单：
  else if (e.which == 3 || this.pointer_is_double) { processContextMenu(...) }

问题：双击第二击 mousedown 到达时，若 pointer_is_down 仍为 true（第一击
mouseup 因 prompt 同步阻塞被延迟/丢失，或第二击早于第一击 mouseup），会置
pointer_is_double=true。此后 processMouseUp 若未走 is_primary 分支复位，该
标志残留到下一次单击，使「单击节点」被误判进右键菜单分支，在单击位置弹出
菜单（内容正是 diagnosis/* + Pin + Clone + Remove）。

修复：在双击状态机消费（willBeDouble）后，强制 pointer_is_double=false，
确保下一击是干净的单击，不再误触发右键菜单。

测试：anchorstest.js 第 9 节新增 3 项断言（含「修复前失败、修复后通过」的
残留复现），共 32/32 通过；labeltest.js 22/22 仍全过；总测试 54/54。
